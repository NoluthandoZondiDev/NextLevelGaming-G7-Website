# Next Level Gaming & Esports Arena - Website (Group 7)

XHAW5112 POE Part 2: Plain HTML website (no CSS or JavaScript as yet).
The styled version will be available after completing Task 3.

## About the Project
Website for Next Level Gaming & Esports Arena, a gaming venue in
Johannesburg offering Gaming Packages (R1500) and Individual
Experiences (R750). The website mirrors the functionality of our
mobile app.

## Key features
- Navigation bar on every page, plus back-links and related-experience links
- Calculate Fees: item table, drop-down for number of bookings,
  discount rules (2 bookings 5%, 3 bookings 10%, 4+ bookings 15%),
  15% VAT, and a cost summary
- Data validation on name, phone and email (HTML5 attributes)
- Contact page with address, phone, email, social links and embedded map
